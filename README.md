# A project on automating ML workflow using scikit-learn pipelines, CML, and GitHub actions.

# Using LLMs to Boost Classical Machine Learning URL classification Models.

The work done involves various pieces:
1.Showing how an ML algorithm can use open-source data to train a URL detector that is able to distinguish lexically, good URLs from bad ones that are more likely to be vehicles of phishing attacks.
2.How an LLM can be interrogated to detect URLs that are more likely to be malicious and offer a cogent explanation of why that is so.
3.We show how the classical LLM can benefit from being retrained after incorporating the LLM feedback so that it is better able to improve its detection edge using real-life URLs.
